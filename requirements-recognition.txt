# Face recognition (optional): detection + embedding backbone.
#
# Default install (this file as-is) pulls the standard PyPI wheels, which
# bundle CUDA support and will use an NVIDIA GPU automatically if present
# (`torch.cuda.is_available()`), falling back to CPU otherwise.
#
# On a machine with no NVIDIA GPU, installing this way still works but wastes
# ~2GB downloading unused CUDA libraries. Avoid that with the CPU-only wheel
# index instead -- --extra-index-url, not --index-url: facenet-pytorch only
# exists on PyPI, not on download.pytorch.org, so replacing the index
# entirely (--index-url) fails to find it (confirmed: "No matching
# distribution found for facenet-pytorch"). --extra-index-url adds the CPU
# wheels as an additional source instead of replacing PyPI.
#   pip install --extra-index-url https://download.pytorch.org/whl/cpu -r requirements-recognition.txt
# Upper bounds are precautionary (see requirements.txt's comment) -- not
# based on any known incompatibility with the next major version, just a
# guard against a fresh install silently pulling one untested against.
torch>=2.2,<3
torchvision>=0.17,<1
facenet-pytorch>=2.5,<3
